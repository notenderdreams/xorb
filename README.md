# xorb

`xorb` is a fast, lightweight command-line tool written in Rust that scans a project directory and bundles its file tree structure and text file contents into clean, LLM-friendly Markdown.

By default, `xorb` respects `.gitignore` rules, automatically ignores binary files, applies code syntax highlighting based on file extension, and copies the formatted output directly to your system clipboard.

## Features

- **Respects Ignore Rules**: Automatically honors `.gitignore`, `.ignore`, and global gitignore settings.
- **Accurate Directory Tree**: Renders clean ASCII tree structure with sorted directory and file branches.
- **Syntax Highlighting**: Detects programming language file extensions and formats code blocks accordingly.
- **Binary & Size Filtering**: Automatically skips binary files and allows custom maximum file size thresholds.
- **Flexible Output Destinations**: Write directly to system clipboard, export to a file, or output to `stdout` for piping.
- **Zero Emojis**: Clean, professional command-line interface.

## Installation

### Linux & macOS (Bash / Zsh)

Run this one-liner in your terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/notenderdreams/xorb/main/install.sh | bash
```

### Windows (PowerShell)

Run this command in PowerShell:

```powershell
iwr -useb https://raw.githubusercontent.com/notenderdreams/xorb/main/install.ps1 | iex
```

### Direct Install via Git

Install directly from a remote Git repository:

```bash
cargo install --git https://github.com/notenderdreams/xorb.git
```

### Build & Install Locally

```bash
git clone https://github.com/notenderdreams/xorb.git
cd xorb

# Standard release build (optimized for speed & LTO enabled)
cargo build --release

# Size-optimized release build
cargo build --profile release-small

# Install locally to cargo path
cargo install --path .
```

## Usage

### Basic Command

Scan the current working directory and copy the markdown bundle to the clipboard:

```bash
xorb
```

Scan a specific directory path:

```bash
xorb /path/to/project
```

### Options & Flags

```text
Usage: xorb [OPTIONS] [PATH]

Arguments:
  [PATH]  Target directory or file path to scan [default: .]

Options:
  -f, --format <FORMAT>       Output format [default: markdown] [possible values: markdown, xml, json]
  -o, --output <OUTPUT>       Write output to a specific file
  -s, --stdout                Print output to stdout
  -n, --no-clipboard          Skip copying output to system clipboard
      --hidden                Include hidden files and directories (dotfiles)
      --no-ignore             Do not respect ignore files (.gitignore, etc.)
      --max-size-kb <BYTES>   Maximum file size in kilobytes to include [default: 1024]
  -i, --include <GLOB>...     Include only files matching pattern (e.g. -i "*.rs" or -i src/*.rs)
  -e, --exclude <GLOB>...     Exclude files matching pattern (e.g. -e "tests/*")
  -d, --max-depth <DEPTH>     Maximum directory recursion depth
      --diff [REF]            Filter to files changed in git diff (e.g. --diff main or --diff HEAD~1)
  -q, --quiet                 Suppress diagnostic status messages
  -h, --help                  Print help
  -V, --version               Print version
```

### Examples

**Output in XML format (ideal for Claude / Anthropic models):**
```bash
xorb -f xml
```

**Output in JSON format:**
```bash
xorb -f json
```

**Filter only Rust source files:**
```bash
xorb -i "*.rs" -i "*.toml"
```

**Exclude test directories:**
```bash
xorb -e "tests/*" -e "benches/*"
```

**Limit directory depth:**
```bash
xorb -d 2
```

**Bundle only files modified in Git (Git Diff mode):**
```bash
xorb --diff
xorb --diff main
```

**Output to stdout and pipe to a file:**
```bash
xorb -s > prompt.md
```

**Write bundle directly to an output file without altering clipboard:**
```bash
xorb -n -o context.md
```

**Include hidden files and ignore size limits:**
```bash
xorb --hidden --max-size-kb 0
```

## Project Architecture

`xorb` is structured around clear module boundaries:

- `src/cli.rs`: Command line interface definitions and argument parsing via `clap`.
- `src/scanner.rs`: Fast single-pass file system traverser and binary/size filter.
- `src/tree.rs`: In-memory directory tree representation and ASCII renderer.
- `src/formatter.rs`: Markdown bundle formatter and token estimation.
- `src/clipboard.rs`: Cross-platform system clipboard interface.
- `src/lib.rs`: Library crate interface exposing core functionality.
- `src/main.rs`: Application entry point and workflow coordinator.
